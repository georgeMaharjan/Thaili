# Thaili 1.4.9

## Bank SMS import

- Choose the exact SMS sender for each selected bank. Thaili imports transactions only from those senders.
- Improve transaction amount and direction detection when messages also contain balances or fees.
- Avoid merging wallet entries when their transaction references conflict.

## Categories and accounts

- Add a category while entering or recategorizing a transaction.
- See category icons and colors in both category pickers.
- Keep bank and account type fixed while editing an existing account.

## Budget and notifications

- Round the daily spending allowance down so it does not exceed the remaining budget.
- Open the matching transaction from a transaction notification, or the recent list when there is no unique match.

## Privacy and app lock

- Show the Thaili mark over app content in the Android app switcher.
- Use one Unlock action with Android's biometric and device-credential fallback.
